# OCI Website — Redesign

A cleaner, calmer redesign of the Online OCI Services portal
(originally run by the Ministry of Home Affairs, Government of India).

## Goals

- Reduce visual noise — one primary action per section, generous whitespace,
  a single accent colour with restrained use of saffron for advisories.
- Replace decorative chrome (heavy gradients, the large hero illustration,
  double process-flow graphics) with one well-structured step list.
- Make the page scannable: clear eyebrow labels, short lede, collapsible
  FAQ accordion, and a track-application form that is visible without a
  pop-up.
- Responsive down to mobile; sticky header; proper focus styles; skip link;
  reduced-motion support.

## Files

- `index.html` — semantic markup, no framework.
- `styles.css` — design tokens, layout, components.
- `script.js` — mobile nav toggle and text-size control.

Open `index.html` in a browser to view.
